# Текст для нового диалога

Помоги опубликовать моё портфолио. Сайт уже работает локально. Сначала проверь доступ к указанным путям, уточни конечный домен и состояние VPS. Продолжай с существующим проектом и данными.

## Пути на Windows

- Репозиторий сайта: `Portfolio`.
- PocketBase: `../Base-de-donnees-Portfolio`. Внутри `pocketbase.exe`, `pb_data`, `pb_hooks`, `pb_migrations`, `backups` и `pb_imports`. Уточни версию по локальному бинарнику перед подбором Linux-версии.
- Исходники схемы и проверок в репозитории: `pocketbase/pb_migrations` и `pocketbase/pb_hooks`. Разовые импорты в `pocketbase/imports`. Они требуют локальных исходников из игнорируемой папки `pocketbase/import-assets`. При переносе готовой базы эти импорты повторно запускать не нужно.
- Локальный запуск: `bun run dev`. Скрипт `scripts/dev.mjs` подключает существующую базу или запускает её. Сайт на `http://127.0.0.1:4330/`, админка базы на `http://127.0.0.1:8097/_/`.

## Архитектура и перенос

- Astro генерирует статический сайт. Команда сборки `bun run build`, папка публикации `dist`, зависимости из `bun.lock`. Ранее планировали Netlify для сайта, GitHub для кода и VPS для PocketBase. На момент аудита локальная ветка main без коммитов и без remote.
- На VPS перенеси согласованную резервную копию существующей PocketBase вместе с файлами хранилища, хуками и схемой. Проверь совместимость версий и права. Настрой постоянный запуск и HTTPS. Базу, резервные копии, пароли и .env в GitHub не добавляй.
- В среде сборки задай `PUBLIC_POCKETBASE_URL` с постоянным HTTPS-адресом базы и `SITE_URL` с окончательным HTTPS-адресом портфолио. Проверяй оба значения в production-сборке. Без первого сборка обращается к localhost, без второго отсутствуют абсолютные canonical и hreflang.
- `src/lib/projects.ts` читает публичные записи при сборке. Браузер загружает медиа из PocketBase, поэтому её HTTPS-адрес должен оставаться доступным после сборки. После обновления проектов потребуется повторная сборка сайта. Часть медиа может ссылаться на внешние хранилища.
- `src/pages/[...route].astro` генерирует FR/EN/RU и страницы проектов. Французский открывается на корневом URL. `src/pages/404.astro` — пользовательская страница ошибки. Старые маршруты мозаики и 3D-лаборатории удалены.
- `public/lab-3d` и `src/lab-3d` содержат рабочие компоненты, GLB, текстуры и декодер Draco. Название папки осталось историческим. Stonehenge используется на главной и на странице проекта, остальные модели — на страницах работ.

## Перед публичным запуском

1. Заполни Mentions légales актуальными данными автора и хостинга. Сейчас это заглушка в `src/i18n.ts` и `src/pages/[...route].astro`. Данные уточни у меня. Резюме пока остаётся без ссылки. PDF добавлю после запуска, когда будет окончательный URL для QR-кода.
2. Проверь production-сборку с настоящими URL. В итоговом HTML и JS не должно быть ссылок на локальную базу. Проверь HTTP-статусы, 404, FR/EN/RU, переход языка с сохранением проекта, фильтры, галереи, ссылки на внешние работы, воспроизведение видео и 3D на телефоне и компьютере.
3. Подключи sitemap для индексации и проверь canonical/hreflang. Метаданные проектов уже берутся из PocketBase. Search Console можно подключить после закрепления домена.
4. Сохрани резервную копию до переноса. После запуска проверь восстановление данных, доступность медиа и какой адрес будет использовать QR-код.
